# MY DOOTEA 4Step 레시피 알고리즘

음료의 배합비를 4단계로 선택하면 자동으로 계산되는 인터랙티브 레시피 커스터마이저입니다.

## 🎯 기능

- **4단계 선택형 UI**: 당 → 베이스 → 티 → 향 순서로 진행
- **배합비 자동 계산**: 100% 기준으로 부형제/덱스트린으로 자동 조정
- **6가지 사전 정의 레시피**: 플레인 요거트, 고구마라떼, 초콜렛 모카 등
- **클립보드 복사**: 배합비 결과를 텍스트로 복사
- **반응형 디자인**: 모바일·태블릿·데스크톱 모두 지원

## 📋 각 카테고리 설명

| 단계 | 설명 | 기본값 |
|------|------|--------|
| **당** 🍬 | 단맛의 종류와 강도 (0~70%) | 표준당 (45%) |
| **베이스** 🥛 | 음료의 바디감과 질감 (35~45%) | 유제품 라이트 (35%) |
| **티** 🍵 | 음료의 핵심 맛과 개성 (0~20%) | 고구마 (10%) |
| **향** 🌸 | 음료의 마지막 풍미 (0~1.5%) | 바닐라 (1.5%) |

## 💡 제조 메모
